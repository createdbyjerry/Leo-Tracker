Surface, layout & motion

Layout — floating glass HUD

There's no top nav — the viewport is full-bleed edge to edge so the planet stays perfectly centered. The brand mark and Update Data button live inside the panel header. One combined "Mission Control" panel (brand + catalog + conjunctions + telemetry) floats top-left, and an expandable 2D ground-track map floats bottom-right — both inset by --layout-inset with a frosted-glass surface so the star field and planet stay visible through them. Below 760px the panels reflow into stacked bars.
